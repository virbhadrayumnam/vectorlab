# VectorLab roadmap

## Phase 1: Core tracing studio

- [x] React and TypeScript application foundation
- [x] Local image import and drag-and-drop
- [x] Initial browser tracing engine adapter
- [x] Adjustable tracing parameters
- [x] Original and vector preview
- [x] SVG download
- [ ] Add automated tests and browser QA
- [ ] Validate package licensing and publish dependency notices

## Phase 2: Editing and production workflow

- [ ] Background removal and transparency controls
- [ ] SVG colour and layer inspection
- [ ] Basic path and shape editing
- [ ] Batch conversion
- [ ] Export presets for SVG, PNG, and PDF
- [ ] Undo and redo

## Phase 3: Advanced workflows

- [ ] Integrate browser-compiled VTracer WebAssembly
- [ ] Move tracing into a Web Worker
- [ ] Progress reporting and cancellation
- [ ] Advanced path cleanup and simplification
- [ ] DXF export evaluation
- [ ] Installable PWA and offline support

## Product principles

1. Local-first: source images remain on the user's device.
2. Open source: MIT-licensed project code, with third-party licences clearly documented.
3. Progressive complexity: keep the first workflow approachable while adding professional controls.
4. Browser-native: no account or backend should be required for basic conversion.
